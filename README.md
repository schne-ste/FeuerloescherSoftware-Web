# 📑 Feuerlöscher Software - Systemanforderungen

### ⚠️ Wichtiger Hinweis zum Webserver

Diese Software wurde speziell für die Nutzung mit einem **Apache Webserver** entwickelt (aufgrund von `.htaccess`-Konfigurationen, URL-Rewriting oder PHP-Modul-Abhängigkeiten).

* **Unterstützt:** ✅ Apache Webserver
* **Nicht unterstützt:** ❌ Nginx Webserver

> **Hinweis:** Die Ausführung unter Nginx führt zu Fehlern (z. B. fehlerhaften Weiterleitungen oder unvollständiger Funktionalität), da die Konfigurationsdateien nicht kompatibel sind. Bitte nutzen Sie Apache, um einen reibungslosen Betrieb zu gewährleisten.
